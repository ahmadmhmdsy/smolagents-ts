# T-13 Task 6 — the L4 and L5 layers Implementation Plan

## Contract

- **Role:** the implementation plan for Task 6 of
  `docs/plans/2026-10-14-v1.5-modules-plan.md`, the last T-13 module: the L4
  pattern layer inside `packages/react` and the L5 styled package beside it.
- **Mutability:** frozen once execution begins. A step that turns out wrong is
  corrected by a dated note beneath the task that owns it.
- **Read when:** executing Task 6, or checking what Task 6 promised.
- **Update when:** a measured result differs from its prediction, or a task is
  added or dropped.

**Goal:** two layers over the shipped L3 primitives — `<RunInspector>` and
`<ChatSurface>` as thin compositions in `@smolagents-ts/react`, and
`@smolagents-ts/react-ui` as the copy-in styled package those patterns use —
every one of them reading only the published barrels.

**Architecture:** three surfaces over one snapshot. **Patterns**
(`packages/react/src/run-inspector.tsx`, `chat-surface.tsx`) sit inside the
existing `AgentRun` provider and read the run through `useAgentRunSnapshot`,
holding no state; the inspector renders the step lane and the chat surface
renders the message list its caller supplies. The **styled layer**
(`packages/react-ui/src/*.tsx` and `styles.css`) is one wrapper per pattern
and leaf, adding a class and forwarding props, over plain CSS aimed at
`.smol-*` classes and `--smol-*` tokens.

**Tech Stack:** React 19.3.0 as a peer, jsdom 30.1.2 with
`@testing-library/react` 16.3.3 in both packages, tsup 8.5.1 ESM-only with
`dts: true`, the existing pack smoke, publint 0.3.25 and attw 0.18.5.

**Spec:** design section 5.3 (the layer table), section 10.3 (L4's definition
and its "no new machinery" clause), the accessibility list closing section 10.2,
and section 14's S6 row. The upstream source is
`smolagents/src/smolagents/gradio_ui.py`. The governing risk is V15-R5 in
`docs/plans/2026-10-14-v1.5-modules-plan.md`.

**Depends on:** S5 (the L3 primitives and their accessibility tests) and S1's
`AgentSession`. Order: 1 → 2 → 3 → 4, then 5 → 6 → 7 → 8 → 9.

**Task ownership:** tasks 1–3 own `packages/react-ui/**` and the L4 files under
`packages/react/`; tasks 4–5 own `examples/vite-app/**`,
`apps/docs-site/**` and `scripts/pack-smoke.mjs`; tasks 7–9 own the scoped
entry, the new component rule, `AGENTS.md`, `docs/attribution.md`,
`docs/01-project.md`, `docs/04-tasks.md`, `docs/03-handoff.md` and
`docs/02-environment.md`.

## Decisions fixed before this plan

- L4 lives in `packages/react` as section 5.3's table says and appends two names
  to the existing barrel. No second package exists for the patterns.
- L5 is `packages/react-ui/`, name `@smolagents-ts/react-ui`, id `react-ui`,
  version `0.0.0` outside the `fixed` group, the siblings' template, depending
  on `@smolagents-ts/core` and `@smolagents-ts/react` and on React only as a
  peer.
- The stylesheet is plain CSS the package ships and the consumer copies. No
  Tailwind, no CSS-in-JS runtime, no build-time framework, no new dependency.
- No new core machinery. The snapshot already carries everything both patterns
  render, and a gap would be recorded as a core change with its own risk.
- The existing accessibility assertions stay green, and the new components add
  their own: `aria-live` on streaming output, `aria-busy` while running,
  keyboard-reachable cancellation, one announcement per tool call.

### Task 2: L4, the two patterns

**Deliverable:** `<RunInspector>` and `<ChatSurface>` compose the L3 primitives
into the two surfaces section 10.3 names, with no state of their own.

**Files:** the two pattern modules under `packages/react/src/`, that barrel and
its surface test, plus two matching files under `packages/react/test/`.

**Notes:** `RunInspector` takes `agent` and `task` like `AgentRun`, renders
the status, the step list with the four action leaves, the planning lane and the
final answer, and passes a `components` override map through unchanged. `ChatSurface` takes `messages`, an optional `onSubmit`,
an optional `disabledReason` and `children`; it renders an ordered transcript
from the message list, and its composer is a real `<form>` whose submit calls
`onSubmit` with the trimmed text. The composer is `disabled` while a run is in
flight and when no `onSubmit` is supplied, and in that state it renders the
reason as visible text wired by `aria-describedby`: finding 2 is why the API is
callback-first rather than an invented `sendMessage`. Both patterns read the
run's status through `useAgentRunSnapshot`, so they render from a bare provider
and assert without an agent. The ten existing names keep their order; the two new
ones are appended. `docs/09-decisions/0005-react-layer-surface.md` owns the
surface convention this extends.

**Verification:** `pnpm vitest run --project react` exits 0 with the two new
files; the surface test fails until the pinned list gains the two names; a
disabled composer carrying a reason is asserted, and no live region is
duplicated.

### Task 3: L5, the styled layer and its stylesheet

**Deliverable:** the styled wrappers and the stylesheet a consumer imports or
copies, each wrapper keeping L3's ARIA untouched.

**Files:** `packages/react-ui/src/{styled-run,styled-step,styled-chat,styles.css,index.ts}`,
`packages/react-ui/test/{styled-run,styled-chat,a11y}.test.tsx`,
`packages/react-ui/test/setup.ts`.

**Notes:** `StyledRunInspector`, `StyledChatSurface`, `StyledToolCall` and
`StyledCodeBlock` add a `.smol-*` class and forward their props, so no role,
`aria-live` or `aria-busy` is re-authored and a wrapper cannot drift from the
primitive it wraps. `styles.css` opens with the token block
(`--smol-surface`, `--smol-text`, `--smol-accent`, `--smol-radius`,
`--smol-gap`, each with a fallback in `var()`) and styles only class names it
owns, so it cannot collide with a consumer's sheet. `setup.ts` registers
testing-library's cleanup from an `afterEach`, which the react package needed
for the same reason. The accessibility file asserts, on the styled tree, that
the live regions, the `aria-busy` attribute and the one-shot tool-call
announcement survive the wrapper.

**Verification:** `pnpm vitest run --project react-ui` exits 0; the styled
tree's `aria-live`/`aria-busy` assertions pass; a keyboard test reaches
`Cancel run`, activates it and observes the cancelled status.

## Risks and rollback

| Risk | Mitigation | Rollback |
|---|---|---|
| V15-R5: a layer needs something the barrel does not publish | Findings 1 and 2 are the two candidates and neither is needed: the inspector reads the step lane, the chat surface takes its own message list | Record the gap as a core change; delete the layer file instead of reaching inside |
| The styled layer re-authors ARIA and drifts from L3 | The wrappers forward props and add a class only, and the a11y file asserts the primitives' attributes on the styled tree | Delete the wrapper and compose the primitive directly |
| attw or publint rejects the stylesheet's delivery | Measured: the CSS stays out of `exports` and is proven by the pack smoke's file check | Keep the sheet in `files` and document a copy step in the README |
| The example's section inflates `site:build` | Task 5 measures the delta and task 6's probe B confirms a number | Drop the section from the example; the package still ships |
| The new package builds before react's declarations exist | The react build runs first in the gate, and the test project aliases both packages to source | Alias react's source in the declaration build for the one session |

## Open questions for the owner

1. **The composer's power.** The callback-only design is forced by finding 2. A
   multi-turn chat is a core change to `AgentSession` and its own plan.
2. **The stylesheet's default look.** This plan ships tokens with fallbacks and
   no theme. A shipped theme is a decision to make before task 3 or after.
3. **Whether L5 covers every primitive.** This plan wraps the two patterns and
   two leaves. If L5 should mirror all ten L3 names, task 3 grows.
4. **The example section versus a separate page.** One page with a second section
   is cheaper for `site:build`; a second page proves the copy-in story better.
