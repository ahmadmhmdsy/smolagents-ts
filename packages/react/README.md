# @smolagents-ts/react

The L2 hooks and the L3 headless primitives that render an `AgentSession`:
`AgentRun` with `Status`, `Steps`, `Cancel` and `FinalAnswer`, and `AgentStep`
with its seven leaves. Nothing is styled, and React is its only peer.

## Install the facade, not this package

`@smolagents-ts/react` is public because the facade's declarations name it.
The facade is the documented entry point, and this package is not it.

    npm install smolagents-ts

## Documentation

The repository's `docs/` tree is the documentation. The published site is
https://ahmadmhmdsy.github.io/smolagents-ts/

Its boundary is `rules/components/react.md`.
