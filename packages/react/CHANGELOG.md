# @smolagents-ts/react

## 0.1.0

### Minor Changes

- The first release of the React layer: the L2 hooks `useAgentSession`, `useAgentRun`,
  `useAgentEvent` and `useAgentRunSnapshot` subscribe to a live `AgentSession`; the L3
  `AgentRun` and `AgentStep` primitives render it headless, class-named, with an override
  slot per step kind; and the L4 `RunInspector` and `ChatSurface` patterns compose them
  into a whole view. Nothing is styled and React stays an optional peer.
