# @smolagents-ts/react-ui

## 0.1.0

### Minor Changes

- 458715a: Add the copy-in styled layer over the L4 patterns and the L3 primitives.

  `@smolagents-ts/react-ui` wraps the headless components from
  `@smolagents-ts/react`, adding a `.smol-*` class per wrapper and forwarding
  props untouched. It ships a plain `styles.css` that a consumer copies into a
  stylesheet it owns. React is its only peer.
