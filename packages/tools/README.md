# @smolagents-ts/tools

The default tools and the collection that assembles them, each built with the
core's `tool()` helper and a Zod input schema, so a model sees a typed name,
a description and a JSON schema.

## Install the facade, not this package

The facade re-exports this package, and that is the only reason it is on the
registry.
It is not the documented entry point; the facade is.

    npm install smolagents-ts

## Documentation

The repository's `docs/` tree is the documentation. The published site is
https://ahmadmhmdsy.github.io/smolagents-ts/

Its boundary is `rules/components/tools.md`.
